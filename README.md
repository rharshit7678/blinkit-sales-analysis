# blinkit-sales-analysis
This project performs Exploratory Data Analysis (EDA) on the Blinkit retail dataset to understand sales performance across different outlet types, product categories, and fat content levels.

The goal is to uncover business insights that can help improve sales strategy and inventory planning.

# Problem Statement
Retail companies like Blinkit operate across multiple outlet tiers and product categories.  
Understanding how sales vary by:

- Outlet Location Type
- Item Fat Content
- Product Category
- Outlet Size

It can help optimize product placement and revenue generation.

This project analyzes historical sales data to extract actionable insights.

# Dataset Information

The dataset contains the following key features:

- Item_Fat_Content
- Item_Type
- Item_MRP
- Outlet_Size
- Outlet_Location_Type
- Outlet_Type
- Item_Outlet_Sales

## Tools & Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Analysis Performed

- Data Cleaning & Preprocessing  
- Handling inconsistent fat content labels  
- Sales analysis by Outlet Tier  
- Sales comparison by Item Fat Content  
- Visualization of trends using bar charts & pie charts  
- GroupBy operations for business aggregation  

# Key Insights

- Tier 3 outlets generated higher total sales compared to Tier 1 and Tier 2.
- Low Fat products contribute significantly to overall revenue.
- Medium-sized outlets perform better in total sales.
- Certain product categories dominate revenue contribution.
